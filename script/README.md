# Local vendor assets for `lcc-math2`

This repository now mirrors the CDN dependencies referenced by
`https://gitlab.com/Lucaspeck/lcc-math2/-/blob/main/index.html` into `/script`.

## Files
- `tailwindcss-browser@4.js`
- `three.r134.min.js`
- `vanta.fog.0.5.24.min.js`
- `font-awesome.6.4.0.all.min.css`

`index.html` has been rewritten to load local paths only (`/script`, `/css`, `/js`) so there is no inline CSS/JS.
